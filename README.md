# Calma · propuesta de diseño

Prototipo navegable de **Calma**, un asistente personal por voz para la dirección de una pyme: le hablas al móvil y te organiza las citas, los encargos y los plazos, y te avisa cuando toca.

- **Ver la propuesta:** https://eleazarrc.github.io/calma-propuesta/
- Funciona en el móvil (a pantalla completa) y en el ordenador.
- Todo es simulado, con **datos inventados**. No hay IA real y no se envía nada a ningún sitio.

Enlaces directos: `?ver=encargos`, `?ver=3` (abre la función 3 de la lista) y `?tema=empresa` (otra paleta de colores).
